# `03` — FEATURED PROJECTS

## 🎵 Harmony

**VR Music Interaction System**

An experimental VR environment where spatial interaction controls musical harmony.

Users interact with virtual elements to transition between musical states while visual and audio feedback respond to their movements.

`Unreal Engine` · `MetaSounds` · `OpenXR` · `Niagara` · `C++` · `Blueprints`

---

## 🏫 CampusSphere

**VR Campus Digital Twin**

A virtual representation of a real-world campus built around spatial data, 3D reconstruction and immersive exploration.

The project explores how physical environments can be captured, reconstructed and experienced inside VR.

`Unity` · `C#` · `VR` · `LiDAR` · `Computer Vision` · `3D Reconstruction`

---

## 🤖 Project Hina

**AI Desktop Assistant**

A desktop assistant built to interact with applications, files and system utilities through a conversational interface.

Features include application control, file discovery, system information, timers, calculations and voice interaction.

`Python` · `CustomTkinter` · `LLMs` · `pyttsx3` · `OS Automation`

---

## 📦 Smart WMS

**AI Warehouse Management System**

An intelligent warehouse management concept combining demand prediction, decision support and automated slotting.

`Python` · `Machine Learning` · `React` · `Node.js` · `PostgreSQL`
